# Sicherheit

Bitte keine Zugangsdaten, Push-Inhalte, Telefonnummern, Standortdaten oder privaten HA-URLs in Issues, Logs oder Pull Requests veröffentlichen.

Sicherheitsrelevante Hinweise bitte zunächst privat an den Repository-Eigentümer melden. Eine öffentliche Security-Policy und ein dedizierter Meldekanal werden vor einer Veröffentlichung ergänzt.
