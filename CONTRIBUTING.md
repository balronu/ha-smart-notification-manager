# Beitragen

Arbeite ausschließlich über Feature-Branches und Pull Requests. Direkte Änderungen auf `main` sind nicht vorgesehen.

Vor einem Pull Request:

```bash
uv run pytest
uv run ruff check .
python -m compileall custom_components
```

Keine echten HA-Zugangsdaten, Push-Inhalte oder personenbezogenen Daten in Code, Tests, Logs oder Issues einchecken.
